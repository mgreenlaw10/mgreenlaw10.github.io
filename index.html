Chess Engine/Bot (C)

A chess engine/bot written in C by me and my lovely girlfriend. It uses no external libraries except for GUI. We implemented the logic for a fully-functioning chess engine from scratch and a bot that plays at ~1000 chess.com ELO with alpha-beta tree search and a static evaluation function.

Rust Text Editor

A terminal-based text editor written in Rust. Supports creating/editing UTF-8 encoded text files in the terminal (Windows or Linux). Extra features include ctrl+s saving, vertical window scrolling, and a working selection window (as you would expect ctrl+arrow or shift+arrow to function in a text editor).
